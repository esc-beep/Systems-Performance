# CHAP 03-4 리눅스   

## 3.4.1 리눅스 커널 개발 
너무 많아서 인상깊은 것 위주로 정리했습니다. 
* overcommit: OOM killer와 함께 함께 사용됨. 더 적은 메모리로 더 많은 프로그램을 실행할 수 있게 해주는 전략 
* tracepoint: 커널 내 논리적 실행 지점에 위치한 정적 계측 지점(static probe). 트레이싱 도구들이 이를 사용해 커널 동작 분석 가능 
* BPF JIT: BPF 바이트코드를 네이티브 명령어로 컴파일하여 패킷 필터링 성능을 향상시키는 JIT(Just in time) 컴파일러
