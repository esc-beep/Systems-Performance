# CHAP 03-3 커널
리눅스는 점점 복잡성이 증가. 새로운 시스템 콜이나 다른 커널 인터페이스를 통해 그 복잡도를 사용자에게 노출하는 중. -> 학습, 프로그래밍, 디버깅에 많은 시간이 소요되기 시작 

## 3.3.1 유닉스 
* 멀틱스라는 운영체제에서 작업함 -> 경량화된 멀티태스크 운영체제와 커널로 개발됨 
* 프로세스에 스케줄러 우선순위 지정 가능 
* 메모리 내 장치별 버퍼 캐시 사용 -> 디스크 데이터를 캐시 가능 

## 3.3.2 BSD
BSD(Berkely Software Distribution). 넷플리스의 CDN 등에 사용됨 
* 페이징된 가상 메모리: 메인 메모리 비우기 위해 전체 프로세스 스왑 아웃 대신 LRU메모리 조각 페이징 
* 요구 페이징: 물리적 메모리가 가상 메모리에 매핑되는 시점을 실제로 메모리에 쓰기 시작하는 시점으로 미룸 
* FFS: 버클리 고속 파일 시스템 -> 디스크 할당을 실린더 그룹으로 묶어 fragmentation을 크게 줄이고 회전 디스크에서의 성능 향상시킴  
* TCP/IP 네트워크 스택 
* 소켓 : 버클리 소켓.
* Jails : 경량 os 수준 가상화 
* 커널 TLS: tls 처리 상당을 커널로 이동시켜 성능 향상

## 3.3.3 솔라리스 
유닉스 및 BSD에서 파생된 커널 및 운영체제 
* VFS(Virtual File System)
* 완전 선점형 커널 
* 멀티프로세서 지원 
* slab allocator 
* DTrace 
* Zones 
* ZFS
