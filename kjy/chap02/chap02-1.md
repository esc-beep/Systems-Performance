# CHAP 02-1 방법론 - 용어 
리스트 형식으로 정리하기에 너무 많기 떄문에, 익숙하지 않거나 몰랐던 부분들 위주로 정리함 

* IOPS(Input/Output operations per second)
    * 데이터 전송 연산에 대한 측정값 중 하나 
    * 디스크 I/O의 경우 IOPS는 초당 읽기와 스기 횟수를 의미 

* 사용률(utilization)
    * 요청을 처리하는 자원의 경우 사용률은 해당 자원이 얼마나 바쁜가를 측정하는 기준 
    * 특정 기간 동안 해당 자원이 작업을 활발히 수행한 시간의 합계로 표현 가능 
    * 저장 장치를 제공하는 자원의 경우, 사용률이란 단어가 용량 중 얼마를 사용했는지를 나타낼 수 있음 

* 포화도(saturation) 
    * 어떤 자원의 큐에 처리하지 못한 작업이 얼마나 많이 남아있는지 정도를 표시
