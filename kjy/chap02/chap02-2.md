# CHAP 02-2 방법론 - 모델 

## 2.2.1 테스트 중인 시트템 
* 테스트 중인 시스템 (system under test, SUT
* 시스템 성능에 영향을 미칠 수 있는 여러가지 교란 요인을 고려해야함 
    * 일부 클라우드 환경에서는 분석이 매우 어려울 수 있음 -> 게스트 SUT에서는 같은 물리적 호스트에서 발생하는 다른 활동(다른 테넌트의 작업) 볼 수 없기 때문 
    * 현대는 여러 복잡한 환경에서 (로드 밸런서, 웹 서버, 캐싱 서버 등..) 각 구성 요소를 단순히 매핑하는 것만으로도 간과했던 교란 요소를 밝혀낼 수 있음 -> 또한 큐 시스템 네트워크로 모델링하여 분석 연구 수행도 가능
